## Identifier

The Software is identified by the SPDX custom license reference:

    LicenseRef-Dust-OS-Proprietary

`LicenseRef-Dust-OS-1.0` (source-available) is retired and must not be applied to
new files. Files that still carry it must be updated when they are next touched.

## Source file headers

Every original source file must carry the following two-line header at the top of
the file, above any include directives:

    /* SPDX-License-Identifier: LicenseRef-Dust-OS-Proprietary */
    /* Copyright (c) 2026 devennw. All rights reserved. Confidential. */

Files that are wholly or partly derived from a Third-Party Component must retain
that component's original copyright and license notice instead. Do not add the
header above to third-party code.

## Contributions and team work

Copyright in work created for the project is assigned to the Owner under a signed
written agreement before the work is merged:

- employees and contractors: [LEGAL/IP_ASSIGNMENT.md](LEGAL/IP_ASSIGNMENT.md);
- any other contributor: the same assignment template, executed individually;
- minors: the assignment must be countersigned by a parent or legal guardian.

Authorship is recorded in git commit metadata and, with consent, in
[AUTHORS.md](AUTHORS.md). Moral rights remain with the authors and are not waived.

## Third-Party Components

Third-Party Components are not owned by the copyright holder and are not covered
by [LICENSE](LICENSE). They are identified, together with their provenance
status, in [NOTICE](NOTICE).

The provenance of copied headers with no notice must be established before any
commercial distribution; see the table in [NOTICE](NOTICE) and the release gate
in [DOCUMENTS/RELEASE_PROCESS.md](DOCUMENTS/RELEASE_PROCESS.md).
